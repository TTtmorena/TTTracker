## Features

TTTracker is a high-performance analytics skill designed specifically for the Bankr ecosystem on Base.

| Capability                    | Description                                              | Status     |
|-------------------------------|----------------------------------------------------------|------------|
| **Live Fee Tracking**         | Claimable + Lifetime fees (WETH + USD)                   | Advanced   |
| **Market Data**               | Market Cap, 24h Volume, Holders                          | Real-time  |
| **Revenue Analytics**         | Weekly revenue + daily earnings history                  | Full       |
| **Top Agents Ranking**        | Rank by revenue / market cap / volume                    | Dynamic    |
| **Comparison Mode**           | Side-by-side token analysis                              | Supported  |
| **Portfolio View**            | “My fees” across all created tokens                      | Complete   |
| **Smart Suggestions**         | Auto-recommend claim when fees are ready                 | Intelligent|
| **Historical Deep Dive**      | Best day, 7d/30d trends                                  | Detailed   |

## Install

Install directly into your Bankr agent:

```bash
install the skill at https://github.com/TTtmorena/TTTracker
```

After installation, the skill activates automatically when you ask about fees, analytics, dashboards, rankings, or TTTracker.
